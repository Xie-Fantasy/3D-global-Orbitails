# 3D 地球需求分析说明书

## 1. 项目背景

相邻项目 `../china-3d-map1` 已实现平面挤出的 3D 中国地图，包含柱状图、飞线、散点、标牌、粒子、路径轨迹、轮廓流光、背景光环、倒影和省市下钻。新需求是在独立的 `globe-3d-map` 项目中，根据其可复用技术、素材与视觉语言，实现参考图二风格的 3D 地球。

参考图二未提供源码和完整交互稿，因此本说明书把静态画面可确认内容、现有项目可复用能力和实现所需的产品假设组合成首版范围。假设项需要在开发中保持可配置。

### 1.1 M6 增量说明

M6 已把最初列在 P2 的地表纹理提前实现：项目内置 4K 白天地表和夜间灯光
贴图，并保留完全关闭贴图的程序化模式。新增首屏资源 Loading、平滑长入场、
国家级球面点击与三层边界辉光。该增量不改变“无在线 GIS、无真实业务下钻、
无动态太阳与气象模拟”的边界。

## 2. 产品目标

- 建立一个可旋转、可缩放、可聚焦的全球 3D 数据可视化场景；
- 在无地球贴图素材的首版中，仍达到明确的球体层次与科技感；
- 将现有柱状图、飞线、标签、运输路径和粒子能力迁移为球面版本；
- 以广州为默认示例枢纽，表达全球城市连接或物流网络；
- 形成可扩展图层架构，后续能替换真实数据和添加纹理；
- 保持相邻中国地图项目独立且不被修改。

## 3. 成功指标

### 3.1 功能

- 6 类图层可独立显隐：柱状图、飞线、标签、陆运线、海航线、粒子光环；
- 地球支持鼠标与触控旋转、缩放；
- 城市标点支持悬停/点击，相关信息与航线可突出；
- 全球、中国、广东三个预设视角可切换；
- 加载失败、空数据和 WebGL 不支持有明确反馈；
- 路由重复进入/离开无明显资源泄漏。

### 3.2 视觉

- 用户在首屏可辨识地球、亚洲区域和广州主枢纽；
- 绿色大气、青色普通线路、黄色关键线路形成清晰层级；
- 球背标签不透出，线路有正确深度遮挡；
- 1366×768 及以上桌面视口不遮挡主要内容；
- 首版不依赖卫星影像或地球纹理。

### 3.3 性能

- 1920×1080 默认档桌面稳态目标 ≥55 FPS；
- 移动端低质量档目标 ≥30 FPS；
- 默认场景 draw calls 目标 ≤120；
- 图层关闭后停止对应 CPU 动画；
- 构建成功，无新增未解释的错误或阻断性警告。

## 4. 用户与使用场景

### 4.1 主要用户

- 数据大屏观看者：快速理解全球连接关系；
- 展示操作者：通过开关与聚焦控制演示节奏；
- 前端开发者：替换数据、增加图层、调整样式；
- 产品/设计人员：配置视角、颜色、默认图层和文案。

### 4.2 核心场景

1. 用户打开页面，看到地球从深空中进入，视角落在亚洲。
2. 广州枢纽高亮，连接国内外城市的线路依次出现。
3. 用户关闭飞线，仅查看陆运/海航路径。
4. 用户打开柱状图，对比各城市指标。
5. 用户旋转地球查看背面城市，标签随可见半球更新。
6. 用户点击新加坡，镜头聚焦并突出广州—新加坡关联。
7. 用户点击“中国”或“广东”预设，镜头切到指定区域。
8. 某数据文件失败时，基础地球仍显示，失败图层提示重试。

## 6. 功能需求

### FR-001 页面与路由

- 新项目根路径 `/` 默认进入地球页面；
- 如需要多页面扩展，可同时保留语义路由 `/three-3d-globe`；
- 新项目不导入相邻中国地图的 Vue 入口、路由或业务场景；
- 未匹配路由回到地球首页或展示 404，实施前明确；
- 页面卸载必须停止 RAF、动画、监听与资源更新。

验收：

- 地球首页可直接刷新访问；
- 来回切换 10 次无多 canvas、CSS3D 容器或持续动画；
- `npm run build` 成功。

### FR-002 基础地球

- 球体使用程序化材质，无地球贴图也可运行；
- 暗面、亮面与轮廓层次清晰；
- 大气层与球体分离；
- 世界边界线贴合球面且不明显闪烁；
- 亚洲默认朝向镜头。

验收：

- 关闭所有业务图层后，仍可辨识地球形态和边界；
- 旋转到任意角度无接缝、翻面和 z-fighting；
- 不加载卫星/地表纹理。

### FR-003 相机与控制

- 桌面支持拖拽旋转、滚轮缩放；
- 移动端支持单指旋转、双指缩放；
- 有最小/最大缩放距离；
- 使用阻尼；
- 自动旋转可配置，用户操作时暂停；
- 视角聚焦动画可被新操作中断。

验收：

- 不可进入球体内部；
- 不可缩放到地球消失；
- pointer 在 canvas 外松开后不锁死；
- 点击 UI 不带动地球。

### FR-004 城市标点

- 数据包含稳定 id、名称、经纬度、类型和优先级；
- 点贴合球面并沿法线外移；
- 默认枢纽广州使用黄色或更强光圈；
- 悬停高亮，点击选中；
- 移动端点击可完成相同行为。

验收：

- 经纬度非法的数据被跳过并记录可理解错误；
- 球背标点由深度正确遮挡；
- 快速切换选中不会残留多个高亮。

### FR-005 标签

- 主枢纽和高优先级城市默认显示；
- 标签显示名称，可扩展类型、数值；
- 球背、视锥外标签隐藏；
- 地平线边缘可淡出；
- 与工具栏重叠时避让或隐藏；
- 图层开关与选中状态一致。

验收：

- 不出现标签透过球体；
- 默认视角主要标签无大面积重叠；
- 关闭标签后 DOM/渲染更新停止；
- 重新打开恢复正确状态。

### FR-006 飞线

- 支持一对多、多对多；
- 默认广州连接多个国内外城市；
- 普通飞线青色，重点飞线黄色；
- 飞线基于球面大圆关系，并在中部抬升；
- 有流动亮头/尾；
- 球体遮挡背面部分；
- 显隐开关不重复创建几何体。

验收：

- 起终点精确落在对应球面点；
- 跨日期变更线不绕错误长路径；
- 起终点相同不生成非法 geometry；
- 接近对跖点时无 NaN 或突跳。

### FR-007 柱状图

- 柱体沿球面法线向外；
- 值域归一化，提供最小可见高度；
- Top N 或选中项可高亮；
- 可配最大数量；
- 显隐带短入场/退场动画。

验收：

- 各纬度柱体方向正确；
- 负数、空值、全零数据有定义；
- 快速开关后最终状态正确；
- 球背柱体正确遮挡。

### FR-008 陆运线

- 支持多控制点路线；
- 路线贴近地表；
- 使用青绿色流动样式；
- 数据缺失时显示空态或禁用按钮；
- 演示数据要有明确标识。

验收：

- 路径通过每个控制点附近；
- 跨日期变更线处理正确；
- 关闭后停止纹理/进度更新。

### FR-009 海航线

- 与陆运线视觉不同；
- 抬升与流速可独立配置；
- 可连接港口点；
- 默认演示路线可根据陆地掩膜自动生成避陆 waypoint；
- 跨 ±180° 经线时路径搜索保持连续；
- 同样支持空、错和显隐。

验收：

- 与飞线、陆运线能同时辨识；
- 新加坡到悉尼的主路径不穿越澳大利亚大陆；
- 不产生过密线束或明显摩尔纹；
- 图层关闭后无更新消耗。

限制：自动规划只用于视觉演示，不包含水深、天气、海流、禁航区和真实航道
规则，不得作为航海导航数据。

### FR-010 粒子光环

- 围绕地球呈倾斜空间环；
- 支持 1～2 条粒子带；
- 可独立关闭；
- 低质量档减少数量或关闭；
- 降低动效设置下静止。

验收：

- 前后深度关系正确；
- 不出现整圈过曝；
- 关闭后 update 不执行。

### FR-011 图层工具栏

- 使用真实 button；
- 支持 active、disabled、loading、error；
- Tab 可聚焦，Enter/Space 可切换；
- 状态来源于场景控制器；
- 窄屏改为底部横向布局。

验收：

- 快速连点 20 次不重复创建图层；
- UI 状态与实际 visible/update 状态一致；
- disabled 有可理解原因。

### FR-012 视角预设

- 提供全球、中国、广东；
- 每项包含目标经纬度、相机距离和可选数据过滤；
- 预设切换使用最短方向平滑过渡；
- 当前项有明确视觉状态；
- 首版称为视角预设，不承诺真实行政下钻。

验收：

- 三个预设均能稳定抵达；
- 动画中切换，以最后一次选择为最终状态；
- 手动旋转后预设状态按规则取消或标为自定义。

### FR-013 加载与错误

- 基础球体优先渲染；
- 数据和边界可渐进加载；
- 局部图层失败不阻断其他图层；
- 支持重试；
- 组件卸载后取消或忽略异步结果。

验收：

- 模拟 404、超时、坏 JSON 时页面不白屏；
- 错误按钮与重试状态正确；
- 重试不叠加对象。

## 7. 数据需求

### 7.1 城市

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `id` | string | 是 | 稳定唯一标识 |
| `name` | string | 是 | 展示名称 |
| `coord` | `[number, number]` | 是 | `[经度, 纬度]` |
| `type` | string | 是 | hub/city/port 等 |
| `value` | number | 否 | 柱状图或 tooltip |
| `priority` | number | 否 | 标签优先级 |
| `icon` | string | 否 | 许可明确的图标 key |

### 7.2 路线

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `id` | string | 是 | 稳定唯一标识 |
| `kind` | string | 是 | flight/land/sea |
| `fromId` | string | 是 | 起点 id |
| `toId` | string | 是 | 终点 id |
| `waypoints` | array | 否 | 陆运/海运控制点 |
| `value` | number | 否 | 业务值 |
| `priority` | number | 否 | 渲染优先级 |
| `color` | string | 否 | 受主题白名单控制 |

### 7.3 数据来源

- 首版可使用本地演示数据；
- 世界边界 GeoJSON 必须本地化并记录来源/许可证；
- 真实业务数据接入前要定义版本、缓存、超时、字段校验和脱敏；
- 禁止把不稳定第三方接口作为唯一运行依赖。

## 8. 非功能需求

### NFR-001 兼容性

- 首要支持最近两个稳定版本的 Chrome/Edge；
- Safari 与移动浏览器作为 P1 验证；
- WebGL2 优先，无法创建上下文时展示降级说明。

### NFR-002 可维护性

- 每类效果独立 layer；
- 所有球面坐标算法只有一个实现；
- 配置与数据分离；
- 图层拥有对称 dispose；
- 中国地图与地球按独立项目隔离；地球内部图层再按目录和模块隔离。

### NFR-003 安全

- 不把不可信内容直接插入 `innerHTML`；
- 外部 JSON 做 schema 校验；
- 不泄露 API token；
- 使用远程素材需受 CSP/CORS 约束并记录来源。

### NFR-004 可访问性

- UI 可键盘操作；
- 具有明确焦点；
- 不只依赖颜色表达状态；
- 支持降低动效；
- 无 WebGL 时仍有文本说明。

### NFR-005 可观测性

- 开发模式可显示 FPS、draw calls、triangles 和资源计数；
- 生产模式保留结构化错误上报接口；
- 不保留无意义 `console.log`。

## 9. 边界与异常矩阵

| 场景 | 预期行为 |
|---|---|
| 城市数组为空 | 显示基础地球；相关按钮 disabled |
| 个别城市坐标非法 | 跳过该项并上报；其余继续 |
| 路线端点不存在 | 跳过路线并关联数据错误 |
| 起终点相同 | 不绘制或绘制点到点脉冲，不创建弧线 |
| 接近对跖点 | 选择稳定辅助轴，避免 slerp 奇异 |
| 跨 180° 经线 | 走最短弧或遵循显式 `arcMode` |
| 标签位于球背 | 隐藏且不参与碰撞 |
| 浏览器切到后台 | 暂停/降频 RAF，恢复后 delta 不突增 |
| WebGL context lost | 暂停渲染并提示；恢复或重建 |
| 路由卸载时请求未完成 | AbortController 取消或忽略结果 |
| 快速开关图层 | 取消旧 tween，收敛到最后状态 |
| 低端设备掉帧 | 自动或手动降低质量档 |
| 视口极窄 | 工具栏移到底部，标签减少 |

## 10. 约束与待确认

### 10.1 已知约束

- 新项目由官方 Vite Vue JavaScript 模板创建，未启用 TypeScript；
- M1～M4 已建立 Vue Router、`globe/core`、独立 layers、数据服务、交互服务与轻量 UI 组件；
- 参考工程 `map.js` 约 1346 行，场景编排与具体效果高度耦合，不应整文件复制；
- 参考工程主 chunk 偏大；新地球已按 Vue、Three.js、GSAP、Geo 与业务页面拆包；
- 参考工程 Sizes 的 window resize 监听未对称移除；
- 参考工程多个组件向 Time 注册匿名回调，不便单独注销；
- 参考工程子地图依赖 DataV 在线接口，不复制到新项目生产链路；
- 新项目当前有 25 项 Node Test Runner 测试，仍未配置 lint 和 TypeScript；
- 世界边界已通过 `world-atlas` 本地打包，不依赖在线 GIS；
- 默认场景已降到 39 draw calls；真实移动设备持续 FPS 仍需发布前补测。

### 10.2 待产品确认

- 根路径是否唯一入口，还是同时保留 `/three-3d-globe`；
- “中国 / 广东”是视角预设还是必须真实下钻；
- 首版是否要求柱状图默认开启；
- 是否要求严格零 PNG（包括点图标和光圈）；
- 是否必须支持手机端；
- 世界边界数据来源与许可；
- 演示城市、航线与指标的真实含义；
- 是否保留自动旋转；
- 是否需要信息面板或只显示名称；
- 是否需要倒影。球体场景建议取消平面倒影。
