# 3D 地球视觉与交互设计

## 1. 设计范围

本设计用于独立项目 `globe-3d-map`。相邻的 `china-3d-map1` 仅提供可复用代码、素材和视觉语言；参考图二提供地球视觉方向，但不是可逐像素复刻的完整设计稿。

### 1.1 可直接观察

- 黑色星空背景；
- 主体为偏右居中的绿色发光地球，视角聚焦亚洲—太平洋；
- 地球外缘有强烈青绿色大气辉光；
- 多条青色/白色/黄色弧线连接城市，广州是高亮枢纽；
- 地理点带同心波纹、图标和黑底标签；
- 左侧为纵向功能开关；
- 底部有“中国 / 广东”等层级或焦点入口；
- 整体是高对比、荧光、数据大屏风格。

### 1.2 设计推断

- 左侧开关按图层显隐处理；
- 地球允许旋转、缩放和点击聚焦；
- 底部入口按“视角预设/层级导航”处理；
- 自动旋转、动画时长、标签避让与默认图层状态均由本设计补充；
- “陆运线”和“海航线”使用不同路径样式；M5 海航采用低分辨率陆地掩膜
  自动避开大陆，但不作为真实航海导航。

## 2. 体验目标

1. 首屏 3 秒内让用户看懂“这是一个全球运输/连接网络”。
2. 广州主枢纽与亚洲区域形成第一视觉焦点。
3. 图层切换立即反馈，不产生闪烁、重复对象或状态错乱。
4. 即使没有地球贴图，也能通过球体层次、国界线、经纬网、大气和光照建立空间感。
5. 控件克制，不遮挡地球与主要航线。

## 3. 视觉概念

主题系统名：**Global Orbit / 全球轨道**

关键词：

- 深空；
- 翡翠绿色；
- 青色信号；
- 琥珀色主航线；
- 透明玻璃标签；
- 克制的军事/物流数据界面。

M5 提供翡翠绿、深海蓝、星云紫、琥珀金四套语义配色；翡翠绿仍为默认，
深海蓝用于接近参考图五的蓝色视觉方向。

M6 增加“无贴图 / 白天 / 夜晚”表面模式。贴图不替代现有程序化网格和
主题色，而是与其混合，保证昼夜模式仍属于同一个 Global Orbit 视觉系统。
首屏先显示深空网格、双轨道扫描球和真实资源进度；Loading 离场后使用
约 4.1 秒的远近景、缩放和经向旋转组合入场。选中国家时，其他国界降亮，
目标边界显示循环流光提示，顶部焦点牌说明再次点击可退出。

不采用：

- 大面积高饱和绿色平涂；
- 无意义的强 Bloom；
- 过密星点、过粗飞线或常亮黄色；
- 参考截图中的水印、站点 Logo 或不明版权图标。

## 4. 页面布局

### 4.1 桌面端

```text
┌──────────────────────────────────────────────────────────────┐
│ 状态/标题（可选）                                  FPS（开发）│
│                                                              │
│ ┌──────────┐                                                 │
│ │ 柱状图   │                 3D 地球                          │
│ │ 飞线     │          标签、弧线、粒子、枢纽                  │
│ │ 标签     │                                                 │
│ │ 陆运线   │                                                 │
│ │ 海航线   │                                                 │
│ │ 粒子光环 │                                                 │
│ └──────────┘                                                 │
│                         [ 全球 ] [ 中国 ] [ 广东 ]             │
└──────────────────────────────────────────────────────────────┘
```

- 地球视觉中心：约在视口 `62% x / 50% y`；
- 地球屏幕直径：视口短边的 72%～88%；
- 左工具栏：距左 24 px，垂直居中；
- 底部导航：距底 24 px，居中或与地球视觉中心对齐；
- 标签和飞线可越出球体轮廓，但不能覆盖工具栏。

### 4.2 窄屏与移动端

- 工具栏改为底部横向可滚动；
- 底部视角预设移到顶部；
- 地球视觉中心回到页面中央；
- 默认减少标签、飞线和粒子；
- tooltip 改为固定底部信息卡；
- 不展示纯 hover 信息。

## 6. 场景分层

从后到前：

1. **背景层**：纯黑渐变 + 稀疏星点；
2. **远景粒子层**：低速漂移，透明度低；
3. **地球暗面层**：深绿色程序化球体；
4. **地表细节层**：程序化经纬网、噪声/扫描纹，可关闭；
5. **行政边界层**：世界国界或海岸线 GeoJSON 转球面折线；
6. **大气层**：略大于球体的背面渲染 Fresnel；
7. **数据层**：柱体、点、陆运线、海航线、飞线；
8. **焦点层**：广州主枢纽光圈、图标、重点弧线；
9. **空间光环层**：倾斜粒子环/赤道环；
10. **CSS 标签层**：仅展示可见半球且通过避让的标签；
11. **UI 层**：工具栏、导航、tooltip、加载/错误态。

“无贴图”现在是可选表面模式：不采样卫星影像，仅保留程序化 shader、
GeoJSON 边界与现有数据图层。白天/夜晚模式采样本地 4K 等距圆柱贴图；
法线、云层和地形贴图仍不在当前范围。

## 7. 球体表现

### 7.1 地球本体

- `SphereGeometry`，默认半径 50；
- 桌面高质量：96×64 分段；移动低质量：48×32；
- 材质以深绿色为底，通过法线、视角和一盏方向光形成明暗；
- 暗面保持可读，不应完全黑；
- 程序化扫描线/经纬网透明度不超过 0.12；
- 国界线比球体半径外移 0.08～0.15，避免 z-fighting。

### 7.2 大气

- 使用第二个略放大的球体；
- BackSide + AdditiveBlending；
- Fresnel 强度在轮廓处增强，正面接近透明；
- 青绿色外缘可有轻微脉冲，但振幅小于 8%；
- 贴球扫描层提供缓慢移动的纬向光幕与细列脉冲；
- `辉光动画` 可独立关闭，关闭时保留静态 Fresnel 轮廓；
- 无后处理时控制 alpha，避免整屏发绿。

### 7.3 星空

- 星点大小至少分 2 档，亮度有随机差异；
- 中心区域密度略低，避免抢地球轮廓；
- 星点缓慢视差，不做高速穿梭；
- `prefers-reduced-motion` 时停用漂移。

## 8. 数据图层设计

### 8.1 柱状图

- 柱体沿球面法线向外生长；
- 基部有一圈微弱青色光环；
- 普通柱：青绿；Top 3 或选中柱：琥珀黄；
- 高度采用归一化 + 最小高度，避免小值不可见；
- 入场从 0 缩放到目标高度，0.6～1.0 秒；
- 同屏默认最多 30 根。

### 8.2 飞线

- 主枢纽默认广州；
- 普通飞线为青色，关键飞线为黄色；
- 轨迹是球面大圆基础上的抬升弧；
- 动画表现为亮头 + 渐隐尾，不让整条线同时高亮；
- 弧高应随球面夹角变化，并设置最小/最大值；
- 背面弧线仍可存在，但需被球体正确遮挡；
- 线宽视觉保持约 1～2 px，不依赖平台不稳定的原生 Line 宽度。

### 8.3 陆运线

- 贴近地表，抬升小；
- 青绿色短虚线或连续流光；
- 使用“细亮核心 + 柔光外轨”，短脉冲密度与速度高于海航；
- 路径数据可由多个经纬度控制点组成；
- 与海航线使用不同色相/速度/图例。

### 8.4 海航线

- 颜色偏蓝青，弧度略高于陆运线；
- 动画速度较慢；
- 可用疏朗虚线与移动亮点；
- 无真实航路数据时必须标记为演示数据。
- M5 默认通过 Natural Earth 陆地掩膜和球面 A* 生成避陆 waypoint；
- 允许港口至近岸的短连接；小岛、礁石、水深和禁航区不在当前能力内。

### 8.5 标签与标点

- 标点由中心点、同心扩散圈和可选图标组成；
- 标签默认不永久显示全部，优先级：选中 > 主枢纽 > 重要城市 > 普通城市；
- 球背标签隐藏；地平线附近淡出；
- 标签被工具栏覆盖时隐藏或重新布局；
- 选中标签用琥珀色边框；普通标签为青绿色边框；
- 标签文本不随地球透视缩小到不可读，可使用 CSS3D/CSS2D 屏幕空间表现。

### 8.6 粒子光环

- 参考图采用围绕地球的倾斜宽环；
- 首版使用 1～2 个不同倾角的粒子带；
- 粒子密度在前景略高，背景受深度遮挡；
- 不使用大面积实体绿色圆环；
- 开关关闭时停止更新。

## 9. UI 组件

项目不引入外部 UI 组件库，使用下列轻量组件：

### 9.1 `EffectToolbar`

- 选项：柱状图、飞线、标签、陆运线、海航线、粒子光环；
- 按钮同时表达 `on/off/disabled/loading/error`；
- 默认不显示 checkbox 图标，用边框、亮度和左侧状态条表达；
- 工具提示解释数据含义与不可用原因。

### 9.2 `GlobeBreadcrumb`

- 首版实际作用为“视角预设”：全球、中国、广东；
- 当前项使用实心或更亮边框；
- 切换只改变镜头和数据过滤，不伪装成尚未实现的行政区下钻；
- 若未来实现真实下钻，再改为语义 breadcrumb。

### 9.3 `GlobeTooltip`

- 显示名称、类型、数值、起终点等；
- M2 桌面端固定在右上信息区，避免与旋转和标签产生高频抖动；
- 移动端固定在底部；
- 内容为空时不渲染空壳。

### 9.4 `GlobeLoading` / `GlobeError`

- 加载：球体骨架可先显示，数据层逐步进入；
- 错误：明确是“地球基础层失败”还是“某图层失败”；
- 局部失败不阻塞其他图层；
- 提供重试按钮，重试过程幂等。

### 9.5 `GlobeLayerNotice` / `GlobeRuntime`

- 空数据或单层失败时，地球继续在线，工具栏分别显示 `EMPTY` 或 `ERROR`；
- 右下角用紧凑琥珀色提示汇总降级层，不使用覆盖地球主体的大弹窗；
- WebGL 恢复时沿用居中轨道 loading，文案切换为“图形上下文恢复中”；
- 桌面标题区显示质量档、FPS 和 draw calls；移动端隐藏运行时数字；
- 诊断数字只承担运行状态，不与业务指标混用。

### 9.6 `ThemeSwitcher`

- 以四个可键盘操作的色点切换全局语义主题；
- active 状态同时使用边框、尺寸和 `aria-pressed`，不只依赖颜色；
- UI 只调用 `world.setTheme(id)`，不得直接修改 Three.js 材质。

## 10. 交互状态

### 10.1 初始状态

- 地球视角：亚洲—太平洋；
- 自动旋转：开启，速度很慢；
- 标签：开启，但仅显示高优先级；
- 飞线：开启；
- 柱状图：关闭或低密度开启，以视觉清晰为准；
- 陆运线、海航线：开启；
- 粒子光环：开启；
- 广州：默认主枢纽。

以上为设计默认值，应写入配置，可被产品调整。

### 10.2 手动旋转

- pointer down 立即暂停自动旋转；
- 拖动使用阻尼；
- pointer up 后保持当前视角；
- 空闲 5 秒后可恢复自动旋转，恢复行为可配置；
- 点击 UI 不触发地球旋转。

### 10.3 聚焦

- 点击城市：镜头沿最短旋转方向平滑转向，使目标位于可视正面；
- 镜头距离轻微收近；
- 目标光圈加强，相关航线升亮，其余降到 30%～50%；
- Esc、点击空白或“全球”预设退出聚焦；
- 聚焦动画约 0.8～1.2 秒，可被新操作打断。

### 10.4 图层切换

- 150～250 ms UI 反馈；
- 3D 图层使用 opacity/scale 短动画，而不是瞬时闪烁；
- 高频切换时取消前一动画并收敛到最终状态；
- 关闭图层后释放临时 tooltip/hover 状态；
- 图层不可用时保持 disabled 并显示原因。

## 11. 动效节奏

| 动效 | 建议时长 | 曲线 |
|---|---:|---|
| 首屏镜头进入 | 1.8–2.4 s | `power3.out` |
| 大气/球体淡入 | 0.8–1.2 s | `power2.out` |
| 数据层错峰进入 | 0.6–1.0 s | `power2.out` |
| 标签出现 | 0.2–0.35 s | `power1.out` |
| 聚焦镜头 | 0.8–1.2 s | `power2.inOut` |
| 图层显隐 | 0.2–0.4 s | `power1.out` |
| 标点脉冲 | 1.2–2.0 s 循环 | linear |

`prefers-reduced-motion` 下：

- 取消首屏长镜头；
- 停止自动旋转和粒子漂移；
- 保留 ≤150 ms 的状态淡入淡出；
- 飞线改为静态轨迹或低频亮度变化。

## 12. 响应式与可访问性

- 以 1920×1080 为主设计尺寸，但不能按固定像素缩放整个页面；
- 1366×768 下工具栏和底部导航不得遮挡地球主枢纽；
- 移动端降低视觉密度，保留核心图层；
- 所有工具按钮使用真实 `<button>`；
- active 状态不能只依赖颜色；
- 文本与背景对比度保持可读；
- canvas 提供无 WebGL 时的替代说明；
- 键盘焦点清晰可见；
- 状态变化用适度的 `aria-live` 文本通知，不播报连续动画。

## 13. 视觉验收清单

- [ ] 无地球贴图时仍能辨识球体、国界与亚洲方向；
- [ ] 地球轮廓辉光清晰但不过曝；
- [ ] 广州在 1 秒内可被识别为主枢纽；
- [ ] 黄色只用于重点信息；
- [ ] 标签不穿过球体显示在背面；
- [ ] 工具栏激活/禁用/错误状态可区分；
- [ ] 飞线从球面出发并被球体正确遮挡；
- [ ] 柱体沿法线生长，不出现统一朝世界 Y/Z 轴；
- [ ] 1920×1080、1366×768 和移动竖屏布局均不遮挡核心内容；
- [ ] 降低动效设置生效；
- [ ] 不含参考截图水印或未授权素材。
