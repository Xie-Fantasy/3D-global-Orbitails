## 已实现

### 数据契约

- `locations.js`：17 个演示节点，包含稳定 `id`、名称、国家、经纬度、类型、连接指数和显示优先级；
- `flightRoutes.js`：16 条从广州出发的演示航线；
- `GlobeDataService`：
  - 经度归一到 `[-180, 180]`；
  - 校验经纬度、类型、数值和优先级；
  - 拒绝重复 ID、缺失端点和相同起终点；
  - 将航线端点解析为只读节点对象；
- 展示值为合成演示数据，不表达真实航班量、物流量或统计口径。

### 球面数据图层

- `MarkerLayer`：
  - 普通节点、枢纽节点、中心点和扩散环；
  - 广州枢纽使用琥珀色；
  - hover、selected 和普通状态；
  - 独立透明拾取体；
- `LabelLayer`：
  - 屏幕空间 DOM 标签；
  - 球背隐藏、地平线渐隐和优先级遮挡；
  - 选中节点优先显示；
  - 图层销毁时移除全部 DOM；
- `FlightArcLayer`：
  - 统一大圆插值；
  - TubeGeometry 避免平台相关的原生线宽问题；
  - 亮头、渐隐尾和线路相位错开；
  - 高优先级航线使用黄色，普通航线使用青绿；
  - 选中节点时降低无关航线亮度；
- `BarLayer`：
  - 数值归一并保留最小高度；
  - 柱体沿球面法线向外；
  - 广州和选中节点使用黄色强调；
  - 默认关闭，用户可通过工具栏开启。

### 交互与 UI

- `GlobeInteractionService`：
  - Raycaster 节点拾取；
  - pointermove 每帧最多处理一次；
  - 过滤球背命中；
  - 区分点击和拖拽；
  - 桌面 hover、触控点击、Esc 退出；
  - 全部指针和键盘监听对称清理；
- 点击节点后相机按球面最短弧聚焦；
- 聚焦期间暂停自动巡航，退出后 5 秒恢复；
- `GlobeTooltip` 显示节点名称、国家、类型、连接指数和坐标；
- 工具栏中的柱状图、飞线和标签已从路线图状态切换为可用状态；
- 陆运线、海航线和粒子光环继续保持 M3 禁用状态。

## 技术权衡

- M2 航线数量较少，每条航线独立使用 TubeGeometry 和材质，以换取简单可靠的选中高亮；超过约 100 条时应改为合并几何或实例化 shader；
- 标签采用 DOM 层，保证中文可读性和 UI 一致性；超过约 40～100 个常显标签时应迁移到精灵图集或 SDF；
- tooltip 固定在桌面右上和移动端底部，不跟随鼠标，避免与旋转、标签和视口边缘发生高频抖动；
- 柱状图默认关闭，维持首屏飞线和标签的视觉主次；
- 演示数据全部本地打包，当前不建立后端请求、重试和缓存层。
